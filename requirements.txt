# Zoltraak Requirements & Prerequisites
# ===============================================

# If you are coming from Python or looking for dependencies to install:
#
# QUICKSTART INSTALL:
#   npm install
#
# RUNNING THE BOT:
#   npm start            # Run in standard mode
#   npm run dev          # Run in auto-reloading watch mode
